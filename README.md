### How I work

- **Provider-agnostic.** Switch OpenAI ↔ Claude by editing one line in `.env`. No code changes.
- **Your API key, your bill.** I never lock you into my infrastructure.
- **Prompts live in files**, not buried in code — rebrand the bot's persona without touching Python.
- **Every bot ships with** a README, `.env.example`, Docker setup and a manual test checklist.
